# GPHH for UAUAR
## Description
Implementation of **Genetic Programming Hyper-Heuristic (GPHH)** for **Uncertain Agricultural UAV Arc Routing (UAUAR)**.
This code solves UAV routing problems under uncertain flight costs, random task demands, edge failures and battery constraints, aiming to minimize total power consumption.

## Environment & Dependencies
### Python Version
Python 3.8+
